Required Field Schema

Both JSON and CSV formats must provide the following columns:

  • subject: e.g. Mathematics, English
  • topic: e.g. Trigonometry, Percentage
  • question_text_en: English text
  • question_text_hi: (Optional) Hindi
  • option_a_en, option_b_en, option_c_en, option_d_en
  • correct_option: 'A', 'B', 'C', or 'D'
  • explanation_en: Detailed step-by-step solution
  • difficulty: Easy, Moderate, or Hard
